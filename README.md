# gomicrox

基于 **go-zero** 框架的 Go 微服务骨架项目。

> **渐进式拆分**：先拆分服务层与代码工程，验证业务后再拆分数据层。适合 Demo/MVP 快速落地，在保证便利性的同时预留架构演进空间。

## 设计哲学

| 阶段 | 目标 | 当前状态 |
|------|------|---------|
| **服务层解耦** | 服务拆分、RPC 通信、独立部署 | ✅ 已完成 |
| **代码工程规范** | 自定义模板、目录结构、一键启动 | ✅ 已完成 |
| **数据层共享(可选)** | 降低初期复杂度，快速验证业务 | ✅ 保留 |
| **数据层拆分** | 按服务独立数据库 | ❌️ 需要时引入 |
| **服务发现** | 动态扩缩容 | ❌️ 需要时引入 |
| **消息队列** | 异步解耦 | ❌️ 需要时引入 |

## 服务架构

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   cmd/app   │     │  cmd/admin  │     │  gRPC GW    │
│  (port 10002)│     │  (port 10001)│     │  (port 10000)│
└──────┬──────┘     └──────┬──────┘     └──────┬──────┘
       │                   │                   │
       └───────────────────┼───────────────────┘
                           │
              ┌────────────┴────────────┐
              │      services/rpc       │
              │  ┌──────────────────┐  │
              │  │       auth       │  │
              │  │      10003       │  │
              │  └──────────────────┘  │
              └─────────────────────────┘
                           │
              ┌────────────┴────────────┐
              │         infra/            │
              │  database/redis/auth/oss  │
              └───────────────────────────┘
```

| 服务 | 类型 | 端口 | 说明 |
|------|------|------|------|
| `cmd/app` | REST API | 10002 | 应用网关（面向客户端），无数据库，纯 RPC |
| `cmd/admin` | REST API | 10001 | 管理后台（面向运营），无数据库，纯 RPC |
| `services/rpc/auth` | gRPC + HTTP Gateway | 10003 / 10000 | 认证中心（数据归属方） |

## 技术栈

- **框架**: go-zero（REST + RPC）
- **ORM**: GORM v2 + PostgreSQL
- **数据库**: PostgreSQL 16（当前共享，业务验证后拆分）
- **缓存**: Redis（go-redis/v9）
- **认证**: JWT（jwt/v4）+ bcrypt
- **校验**: go-playground/validator/v10
- **代码生成**: goctl + 自定义模板
- **容器化**: Docker + docker-compose

## 快速开始

```bash
# 1. 下载依赖
go mod download

# 2. 密钥配备, 參考 docs/SECRETS.md

# 3. 启动服务 + Docker 基础设施
make dev

# 4. 验证
make smoke-test
```

## 项目结构

```
.
├── cmd/                    # REST API Gateway 层（无数据库，纯 RPC 调用）
│   ├── app/                # 应用网关
│   └── admin/              # 管理后台
├── services/rpc/           # gRPC 业务服务层（数据归属方）
│   └── auth/               # 认证中心
├── infra/                  # 基础设施层（所有服务共享）
│   ├── database/           # GORM PostgreSQL 封装
│   ├── redis/              # go-redis 客户端
│   ├── auth/               # JWT / bcrypt
│   ├── oss/                # 阿里云 OSS
│   ├── errors/             # 通用错误变量
│   └── rand/               # 随机工具
├── model/                  # 数据模型层（共享，后续下沉到各服务）
├── tpls/                   # goctl 自定义模板
├── scripts/                # 开发脚本
├── Makefile                # 常用命令
├── docker-compose.yml      # Docker 编排
└── Dockerfile              # 服务镜像构建
```

每个目录下都有 `README.md`，包含该层的详细架构规范。点击目录查看具体规范。
